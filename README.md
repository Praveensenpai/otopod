**`otopod`** (音Pod) is a high-performance terminal utility written in Rust that replaces [impd](https://github.com/Ajatt-Tools/impd). It condenses raw anime video files into pure Japanese dialogue audio using subtitle timestamps — in a **single ffmpeg pass**, with **zero temporary files** and in **under 3 seconds**.

Designed to pair directly with [**subsink**](https://github.com/Praveensenpai/subsink) for a complete end-to-end Japanese passive immersion pipeline.

---

## ✨ Features

- ⚡ **Single-Pass Audio Condensing**: Parses subtitle timestamps and runs one `ffmpeg` `aselect` filter directly to the output `.ogg` file — no 150+ temp chunks in `/tmp`.
- 🦀 **50× Faster than `impd`**: Condenses a full 24-minute anime episode in **2–3 seconds** instead of 80+ seconds.
- 💾 **Zero Disk Thrashing**: No temporary chunk files. Minimal RAM (< 15 MB).
- 🔍 **Auto Subtitle Detection**: Automatically finds `<stem>.ja.srt` or `.ja.ass` generated by `subsink` alongside your video file.
- 🎵 **MPD-Ready Output**: Writes condensed audio directly to `~/Music/immersionpod/current/` for instant MPD playlist integration.
- 📊 **Retention Stats**: Reports condensed duration and percentage of original audio retained.
- 🎨 **Minimalist Dark TUI**: Clean terminal UI with spinners, progress cards, and deep anime color palette.

## 📊 Performance vs `impd`

| | `impd` (bash) | **`otopod`** (Rust) |
|:---|:---:|:---:|
| Episode condense time | ~82 seconds | **~3 seconds** |
| Temp files created | 150+ chunks in `/tmp` | **Zero** |
| RAM usage | Heavy | **< 15 MB** |
| ffmpeg passes | One per subtitle line | **Single pass** |

## ⚙️ Prerequisites

1. **Rust & Cargo**:
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

2. **ffmpeg** (for audio extraction and condensing):
   ```bash
   # Arch Linux / Omarchy
   sudo pacman -S ffmpeg
   ```

3. **A synced `.ja.srt` subtitle file** alongside your video.
   > Use [**subsink**](https://github.com/Praveensenpai/subsink) to automatically fetch and align Japanese subtitles!

## 🚀 Installation

```bash
git clone https://github.com/Praveensenpai/otopod.git
cd otopod
cargo build --release
install -m 755 target/release/otopod ~/.local/bin/otopod
```

## 🎧 Usage

### Interactive Mode
Run `otopod` anywhere — it scans `~/Videos` and presents an interactive file picker:
```bash
otopod
```

### Direct File Argument
Pass the video file directly for instant condensing:
```bash
otopod "Ore wo Suki nano wa Omae dake ka yo - 01.mkv"
```

---

## 🔄 Full Immersion Pipeline

Pair with [**subsink**](https://github.com/Praveensenpai/subsink) for a complete one-two workflow:

```bash
# Step 1 — Fetch & auto-sync Japanese subtitles
subsink

# Step 2 — Condense anime audio using synced subtitle timestamps
otopod "Anime Title - 01.mkv"

# Step 3 — Update MPD playlist and start background immersion audio
mpc update && mpc play
```

```text
[Raw .mkv] ──► [subsink] ──► [.ja.srt] ──► [otopod] ──► [condensed .ogg] ──► [mpd / background immersion]
```
